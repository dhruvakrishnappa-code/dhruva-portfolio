# Dhruva BS - Portfolio

Personal portfolio website. Static HTML/CSS/JS, no build step.

Live: https://dhruvabs.vercel.app

## Sections

- Hero with name, role and terminal animation
- About
- Skills
- Projects (featured: Phishing URL Detector - India Edition)
- Education & experience
- Contact

## Customizing

- **Photo**: replace the `.photo-placeholder` block in `index.html` with
  `<img src="photo.jpg" alt="Dhruva BS">` and add `photo.jpg` to this folder.
- **Social links**: look for `SOCIAL_LINKS` comments in `index.html`.

## Deploy

Any static host works (Vercel, Netlify, GitHub Pages). On Vercel: import the
repo, framework preset "Other", no build command.
